# 10 · ENV AND KEYS GUIDE
## Every Variable, Where to Get It, Cost

---

## FRONTEND ENV VARIABLES (`.env.local`)

| Variable | Where to Get | Cost |
|---|---|---|
| `NEXT_PUBLIC_SANITY_PROJECT_ID` | sanity.io → project settings | Free |
| `NEXT_PUBLIC_SANITY_DATASET` | Always `production` | Free |
| `NEXT_PUBLIC_SANITY_API_VERSION` | Always `2024-01-01` | Free |
| `NEXT_PUBLIC_API_BASE` | `https://zahidaan.in` | Free |
| `NEXT_PUBLIC_PHONEPAY_UPI_ID` | PhonePe Business app → UPI ID | Free |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | Client's WhatsApp number (with country code, no +) | Free |

## BACKEND PHP CONSTANTS (`api.php`)

| Constant | Where to Get | Cost |
|---|---|---|
| `DB_HOST` | MilesWeb cPanel → MySQL → hostname (usually `localhost`) | Free |
| `DB_NAME` | Created in MilesWeb cPanel MySQL | Free |
| `DB_USER` | Created in MilesWeb cPanel MySQL | Free |
| `DB_PASS` | Set during MySQL user creation | Free |
| `SMTP_HOST` | MilesWeb cPanel → Email → SMTP hostname | Free |
| `SMTP_USER` | Create email account in MilesWeb cPanel (e.g. orders@zahidaan.in) | Free |
| `SMTP_PASS` | Set during email account creation | Free |
| `OWNER_EMAIL` | Client's personal email for order notifications | Free |
| `OWNER_PHONE` | Client's WhatsApp number | Free |
| `SANITY_WEBHOOK_SECRET` | Generated by you → set in Sanity dashboard + here | Free |
| `GITHUB_PAT_TOKEN` | GitHub → Settings → Developer settings → PAT (repo + workflow scope) | Free |
| `COD_MINIMUM` | Client decision | N/A |
| `COD_CHARGE` | Client decision | N/A |
| `FREE_SHIPPING_THRESHOLD` | Client decision | N/A |
| `SHIPPING_CHARGE` | Client decision | N/A |
