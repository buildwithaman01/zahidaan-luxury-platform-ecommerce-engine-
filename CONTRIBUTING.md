# Contributing to ZAHIDAAN

Thank you for your interest in the ZAHIDAAN platform! While this is currently a boutique project for a specific client, we welcome architectural feedback and technical suggestions.

## Development Workflow

1. **Fork the Repo**: Create your own copy of the project.
2. **Setup Environment**: 
   - Follow the instructions in [README.md](README.md) for local setup.
   - Ensure you have a Sanity.io account for CMS testing.
3. **Branching**: Use descriptive branch names (e.g., `feature/seo-improvement`, `bugfix/cart-persistence`).
4. **Pull Requests**: Submit clear PRs with a description of the changes and why they are necessary.

## Coding Standards

- **TypeScript**: Strict typing is required for all new components.
- **Tailwind CSS**: Use utility classes for styling; avoid custom CSS where possible.
- **Documentation**: Update the relevant files in the `/docs` folder if you change system architecture or SEO logic.

## Ethical Note
This project represents a premium spiritual brand. Please ensure any contributions respect the brand's visual and ethical identity.
